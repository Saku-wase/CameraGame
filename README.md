# CameraGame

ブラウザで遊べるミニゲーム集です。

| ゲーム | ファイル | 内容 |
|---|---|---|
| リズムポーズ | `index.html` | カメラに映ってビートに合わせてポーズ |
| スマホラケット・テニス | `tennis.html`（PC）＋ `racket.html`（スマホ）／`ios/`（iPhoneアプリ版） | スマホをラケットにしてCPUとテニス |

## スマホラケット・テニスの遊び方

1. PCのブラウザで `tennis.html` を開く（**https のURLで開く必要があります**。GitHub Pages など）
2. 画面のQRコードをスマホで読み取り、「スタート（センサーON）」をタップ
3. PC画面の「スタート」（またはスマホのボタン）で試合開始
4. スマホ画面の下半分に親指を置いて動かし、選手を移動する（**置いた場所がスティックの中心**になります）
5. ボールが来たらスマホを**振って**打つ！
   - **スイングの速さ（km/h）**を測っていて、速く振るほど強い球になります（スマホとPCの画面に表示。自己ベストも記録）
   - タイミングがぴったりだと「パーフェクト」（早く振ると左、遅く振ると右にずれます）
   - スマホを**傾けて狙う**：左右に傾ける＝左右、奥に倒す＝深い球、手前に倒す＝浅い球
   - 狙いの「まっすぐ」は「スタート」を押したときの持ち方です（「傾きの基準をリセット」で取り直せます）
   - 右側の球はフォアハンド、左側の球はバックハンドで打ちます
   - サーブはトスが高い時に振ります
6. 「視点切替」ボタン（PCは V キー）で一人称と三人称を切り替えられます
7. PCのメニューで「移動：おまかせ」を選ぶと、移動は自動になります

スマホがなくても、PCの矢印キーで移動、W A S D で狙い、Space キー（またはクリック）でスイング、V で視点切り替えして遊べます。

### 音
- **PC**：BGM、観客のざわめき・拍手・歓声、風や鳥の声、ボールのバウンド、相手（CPU）の打球音、審判コール（英語）
- **スマホ**：自分のラケットの打球音（当たり方で変わる）と、素振りの風切り音
- PCのメニューでBGM・観客と環境音・審判コールをそれぞれオン／オフでき、M キーで消音できます。スマホの「設定」→「打球音」で音量を選べます
- スマホがつながっていないときは、自分の打球音もPCから鳴ります
- 音はすべてプログラムでその場で作っています（音声ファイルは使っていません）

### しくみ
- スマホとPCは WebRTC（PeerJS）で直接つながります。サーバーの用意は不要です（接続の仲介にPeerJSの公開サーバーを使います）
- iPhone は https でないとモーションセンサーが使えません
- ヒット時、Android は振動、iPhone のブラウザは音で知らせます
- iPhone で振動させたい場合は、iPhoneアプリ版（`ios/` フォルダ。手順は [ios/README.md](ios/README.md)）を使ってください
