# CameraGame

ブラウザで遊べるミニゲーム集です。

| ゲーム | ファイル | 内容 |
|---|---|---|
| リズムポーズ | `index.html` | カメラに映ってビートに合わせてポーズ |
| スマホラケット・テニス | `tennis.html`（PC）＋ `racket.html`（スマホ） | スマホをラケットにしてCPUとテニス |

## スマホラケット・テニスの遊び方

1. PCのブラウザで `tennis.html` を開く（**https のURLで開く必要があります**。GitHub Pages など）
2. 画面のQRコードをスマホで読み取り、「スタート（センサーON）」をタップ
3. PC画面の「スタート」（またはスマホのボタン）で試合開始
4. ボールが手前に来たらスマホを振る！
   - 速く振るほど強い球（深い球）になります
   - タイミングがぴったりだと「パーフェクト」
   - スマホを左右に傾けるとコースを狙えます（早く振ると左、遅く振ると右にずれます）
   - サーブはトスが高い時に振ります
5. 移動は自動です

スマホがなくても、PCの Space キー（またはクリック）でスイング、← → でコースを選んで遊べます。

### しくみ
- スマホとPCは WebRTC（PeerJS）で直接つながります。サーバーの用意は不要です（接続の仲介にPeerJSの公開サーバーを使います）
- iPhone は https でないとモーションセンサーが使えません
- ヒット時、Android は振動、iPhone は音で知らせます
